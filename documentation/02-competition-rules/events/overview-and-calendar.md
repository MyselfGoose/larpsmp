# Events overview and calendar

**Status:** Event set partly **Confirmed**. Schedules and some formats **Open**. Capture, auctions, Ace Hunt, and Gladiators automation are **Implemented**; natural disasters remain unconfirmed.

## Confirmed event types

| Event | Status |
|-------|--------|
| Daily capture points | Confirmed |
| Gladiators | Confirmed; Day 4 format detailed — see [Gladiators](gladiators.md) |
| Mystery shulker auctions | Confirmed — see [Auctions](auctions.md) |
| Ace Hunt | Confirmed as Day 3 design — see [Ace Hunt](ace-hunt.md) |
| Natural disasters | Maybe only — **not confirmed** |
| Egg hunt / VIP protection | **Rejected** |
| “Objective finale” | Not understood/approved — **do not** treat as promised |

Repeating the strongest activities across five days is preferred over inventing many unique minigames.

## Suggested five-day calendar

**Suggestion** (editable starting idea; not the agreed schedule). Server stays open between sessions.

| Day | Organized activities | Why |
|-----|----------------------|-----|
| 1 | Opening, team setup, daily captures | Learn world and money |
| 2 | Daily captures, first auction | Resources/money make bidding interesting |
| 3 | Daily captures, **Ace Hunt** | Central hunt event with recovery time after |
| 4 | Daily captures, **Gladiators** | Structured arena day |
| 5 | Final captures, agreed final activity if any, wealth count | Clear finish |

Earlier drafts swapped Gladiators and Ace Hunt days; the current design places **Ace Hunt on Day 3** and **Gladiators on Day 4**.

## Scheduling principles

- Exact dates, start times, timezone, and final wealth cutoff: **Open**.
- Players are responsible for showing up; events do not wait until everyone is online (**Confirmed**).
- Admins may delay when something goes wrong.
- **Suggestion:** announce the five-day calendar before open; show “next event” somewhere checkable.

## Missed starts / restarts

**Open:** What happens if the server is offline at a scheduled start.

**Confirmed intent:** important event state should resume after restart where possible (balances always; capture/auction/death IDs must not double-pay).

## Travel

**Suggestion:** normal travel for captures; admin teleport (or temporary join) for Gladiators and auctions.
